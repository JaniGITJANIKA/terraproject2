# Terra Project 2 vagyis  memória kártyák

Egy React + Vite alapú memóriajáték, amelyben természetes elemeket kell párosítani. A projekt tanulási célból készült, és lehetőséget ad arra, hogy egyszerű React logikát, CSS stílusokat és router használatát gyakorold.

## 🎯 Projekt célja

- memóriajáték létrehozása,
- képek és párosítások kezelése,
- különböző természeti elemek bemutatása,
- szép grafikai felület és egyszerű navigáció,
- tanulási és kísérletezési lehetőség Reactben.

## 🧩 Használt technológiák

- React
- Vite
- JavaScript
- CSS
- react-router-dom
- canvas-confetti

## 🚀 Telepítés

1. Nyisd meg a projektet a terminálban.
2. Futtasd ezt a parancsot:

```bash
npm install
```

## ▶️ Futtatás

Fejlesztői módban:

```bash
npm run dev
```

Ez a Vite fejlesztői szervert indítja el, általában itt:

```text
http://localhost:5173/
```

## 🏗️ Build elkészítése

```bash
npm run build
```

A build után a `dist/` mappa tartalmazza a kész alkalmazást.

## 🕹️ Játékszabály

- A játékban kártyák vannak elhelyezve.
- A kártyákat meg kell fordítani.
- Ha két azonos képet találsz, a pár helyes.
- Ha minden párosítás elkészült, a játék nyert állapotba kerül.
- A nyertes üzenet és a gratuláció megjelenik.
